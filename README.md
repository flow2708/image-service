# image-service

Микросервис-прокси для скачивания изображений по URL. Часть экосистемы проекта [Social Network](../social-network-spring).

Принимает URL изображения, скачивает его с внешнего источника и отдаёт клиенту как бинарные данные с сохранением оригинального `Content-Type`.

## 🎯 Назначение

Сервис решает три задачи:

1. **Обход CORS** — браузер не может загрузить изображение с чужого домена напрямую
2. **Единая точка входа** — все внешние изображения идут через один сервис
3. **Будущее кэширование** — скачали один раз, отдаём много раз (в разработке)
